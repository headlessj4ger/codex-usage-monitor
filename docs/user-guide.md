# Codex 用量透视 2.7.0

Windows 原生托盘程序，用于查看本机 Codex 的会话用量、周配额估算、会话关系及活动速率。

## 启动与退出

1. 将整个程序文件夹解压到固定、可写的位置，双击 `Start.cmd`。
2. 首次启动自动读取本机 Codex 数据并建立缓存。后续启动复用已有实例，恢复上次窗口模式。
3. 关闭主窗口会收起到托盘。双击托盘图标可恢复，从托盘菜单选择“退出程序”才会停止采集。

随包提供 Node.js 24.12.0 x64 和许可证。界面使用 Windows PowerShell 5.1 与 WPF；无需安装 npm 包。Acrylic 毛玻璃效果依赖 Windows 11 的桌面合成支持。

启动参数：`Start.cmd -Mini` 打开小窗，`-Main` 打开主窗，`-Tray` 收起到托盘，`-Check` 检查运行环境。

## 主窗口

- **进行中**：会话自身的输出速率、本轮耗时、趋势、响应频率和命令耗时。
- **全部会话**：累计与周期用量、主会话、子会话、分叉及附属关系。可搜索、展开和排序。
- **模型与校准**：按模型、思考深度和服务档位分组，查看经验系数、样本进度及验证结果。
- **进程关联**：本机 Codex 相关进程的 PID、父进程、内存和累计 CPU 时间。

每行默认只计会话自身，详情另列自身与子树的合计。CSV 导出含会话标题、标识和用量。

## 悬浮小窗

从主窗口点击“小窗”，或按 `Ctrl+Shift+M`。小窗支持置顶、拖动、展开主窗口及独立刷新设置。

| 状态 | 显示与操作 |
| --- | --- |
| 刚开始 | 薄荷色点，速率暂为横线 |
| 进行中 | 薄荷色点、近 5 分钟柱形、近 1 分钟输出均值 |
| 待回答 | 琥珀色点、右侧问号，点击打开会话 |
| 失败 | 珊瑚色点、右侧感叹号，点击查看并收起 |
| 中断 | 整行置灰，点击查看并收起 |
| 完成 | 右侧勾选，点击查看并收起 |

子会话排列在父会话下方。最多显示 6 行，更多内容可滚动。标题和详细状态可悬停查看。

状态变化保留原位动画，刷新不会整体重建列表。刷新菜单中的“减少动画”可关闭动效。程序也遵循 Windows 动画和高对比度设置。

完成、失败和中断会保留到本地确认或客户端已读；新完成行至少显示约 4 秒。首次启动只接入最近 15 分钟的未读终态。超过 10 分钟无活动的进行中会话会从小窗收起，主窗口仍可查看。

## 刷新与快捷键

会话状态和新入账用量监听本地记录变化，每秒检查补漏。刷新菜单设置的是完整统计的采样间隔；选择“仅手动”会暂停自动监听和采集。

Windows 进程独立采样，自动采样至少间隔 15 秒。慢速进程查询不会阻塞会话状态。

| 按键 | 操作 |
| --- | --- |
| `F5` | 立即采集 |
| `Ctrl+F` | 搜索会话 |
| `Ctrl+Shift+M` | 打开小窗 |
| `Enter` | 打开选中的小窗会话 |
| `Esc` | 关闭菜单、收起详情或将小窗收起到托盘 |

## 统计口径

近 1 分钟输出速率为窗口内已记账的输出 token 除以 60；近 5 分钟同理。输出包含推理 token。柱形每根覆盖 30 秒，所有可见会话共用刻度。

Codex 通常在响应结束后记录用量。速率是已完成响应的窗口均值；显示 0 时仍可能正在推理、生成或执行工具。缺少记录时显示“未知”，而不是估造数值。

账户周配额来自本机日志快照。逐会话占比是自动学习的估算，通过样本与验证门槛后才启用；新模型自动形成新的分组并积累样本。详细规则见 `docs/metrics.md`。

进程与会话只按明确标识关联。Codex 执行编号不是 Windows PID；短于采样间隔的进程可能没有被采到。

## 数据与升级

默认只读 `%USERPROFILE%\.codex`；设置 `CODEX_HOME` 后使用指定目录。程序读取会话元数据、日志和历史状态，不读取 `auth.json`，不保存对话正文、完整命令参数或工具输出。

ZIP 版的数据保存在 `data/usage-v2.sqlite`，界面设置在 `settings.json`。升级时退出程序，再用新包覆盖程序文件，保留这两处即可。可整体复制程序文件夹进行备份。

npm 版通过 `codex-usage-monitor` 启动，数据和设置保存在 `%LOCALAPPDATA%\CodexUsageMonitor`；更新安装包会保留这些数据。可用 `codex-usage-monitor data-path` 查看实际位置，用 `doctor` 检查安装环境。两种安装方式都支持绝对路径环境变量 `CODEX_MONITOR_DATA` 指定独立数据目录。

状态同步取决于 Codex 写出记录。当前版支持已验证的异步问题提醒，权限审批的客户端内存状态尚未接入。点击会话由系统协议交给 Codex，不会代替用户回答或批准。

## 动效演示与故障排查

双击 `Demo.cmd`。演示使用模拟数据，支持暂停、继续、下一步、重播、阶段选择及播放速度调整。点击状态行可模拟回答或退场，关闭任一演示窗口即可结束。

启动失败时查看提示和 `data/startup-error.log`。采集停止时按 `F5` 重试；界面错误记录于 `data/ui-errors.log`。分享日志前请检查其中的本机路径。

卸载前取消程序内的开机启动，再退出程序并删除程序文件夹。
