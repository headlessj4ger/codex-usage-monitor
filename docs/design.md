# 视觉规范

沿用用户确认的深灰蓝原生 Acrylic 小窗。主窗口采用紧凑三列工作区，与小窗共用字体和主题。状态文案集中于悬停和无障碍名称。

## 颜色与字体

| 用途 | 颜色 |
| --- | --- |
| 侧栏 / 主内容 / 详情 | `#242936` / `#292E3B` / `#2C3240` |
| 主要 / 次要文字 | `#F0F1F4` / `#B5BDCD` |
| 分隔线 / 选中背景 | `#404756` / `#3B4657` |
| 活动 / 提醒 / 失败 | `#8AD7BA` / `#DEBF83` / `#F2949A` |
| 中断标题 / 辅助文字 | `#929BAA` / `#7E8999` |

中文使用 Microsoft YaHei UI，英文及数字使用 Segoe UI Variable Text。数字启用等宽数字排版。透明表面使用灰阶抗锯齿。

## 原生边界与材质

WPF `WindowChrome` 将内容延伸到整个窗口。DWM 统一管理 Acrylic、圆角与细边框；内容层不再叠加圆角底板。

移除原生系统标题栏按钮和标题栏填色。失焦时只保留非客户区的活动绘制状态，真实输入焦点正常转移。关闭窗口时释放消息钩子；不通过降低整窗透明度模糊文字。

## 主窗口与交互

208 DIP 侧栏、弹性列表、350 DIP 详情，窄窗口分别收缩为 184 和 310 DIP。最小窗口为 1020 × 680 DIP。详情可关闭，溢出内容可滚动。

数据通过 DataTable / DataRowView 增量通知。选中项、树展开状态、图表容器和滚动位置保持稳定。菜单支持原生键盘操作和 Escape，关闭后返回触发按钮。

## 设计依据

`design/mini-layout.png` 保存布局与柱形参照，`design/mini-states.png` 保存精简状态参照。两张图由 imagegen 生成，展示的是模拟数据。

工作区结构参考 Linear，深色工具面板参考 Raycast。具体材质、字体和间距以用户确认的实际小窗为准。

Logo 为“分支脉冲”：靛紫圆角方块中的白色三节点分支。原稿在 `src/assets/logo.png`，`app.ico` 包含 16 至 256 px 的七种尺寸。

动效时序见 [动效规范](motion.md)。控件渲染测试验证布局，DWM 属性与实际桌面观察验证毛玻璃；两类证据分别记录。
