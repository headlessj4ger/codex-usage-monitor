# 用量、速率与校准

## token

优先使用按响应 ID 去重的 `token_usage_record`。旧日志使用累计值差分。已知同一笔响应同时出现在累计记录时，只计一次。分叉和审查子会话的继承用量用于建立计数基线。

缓存输入已包含在输入中，推理输出已包含在输出中，均不重复相加。每行只计会话自身，详情可另看自身与子树合计。

日志被清理后，保留已有缓存。元数据累计快照只能用于确认累计用量。包含继承用量且缺少自身记录时，显示自身用量未知。

## 速度

- 近 1 分钟输出速率：窗口内输出 token / 60。
- 近 5 分钟输出速率：窗口内输出 token / 300。
- 非缓存消耗：未缓存输入 + 输出，折算为 token/min。
- 响应频率：窗口内完成并记账的模型响应数。
- 本轮平均输出：本轮输出 / 从开始到当前或结束的墙钟时间，包含工具、排队和等待。
- 已记录命令耗时：合并命令起止区间，重叠部分只计一次。

固定窗口不会随刷新间隔改变分母。首个响应入账等待不等于首 token 延迟；模型纯生成速度不能由这些日志准确还原。

## 周配额

账户周配额是日志中的快照。有效周期取重置时间之前的 7 天。快照缺失或过期时采用北京时间自然周，并暂停周配额估算。所有显示时间均为北京时间。

周配额估算截至快照时间。快照之后的 token 继续计入本机用量。详情展示估算状态及对应时间。

模型表的「周期用量占比」是该组合的估算用量占账户已用额度的比例。「周期总量占比」是同一估算用量占整周期账户额度的比例。两列以同一份快照为准。缺少有效快照时，用量占比显示本机计费权重，周期总量占比等待快照。

## 自动校准

程序按模型、思考深度和服务档位分组，自动更新每百万 token 对应的配额百分点。模型范围取 Codex 下载到本机的可见模型目录。目录缺失时，使用随程序附带的[官方模型清单](https://learn.chatgpt.com/docs/models)。新模型出现在目录后自动纳入。

未知模型、隐藏的自动审批模型和其他目录外模型只保留在会话 token 记录中。它们的用量区间不参与拟合。缺少思考深度或服务档位的记录仍标为“未记录”。

### 本机计费权重

程序按 [Codex 公布的积分费率](https://learn.chatgpt.com/docs/pricing#token-rates) 分别计算未缓存输入、缓存输入和输出。模型详情用“积分 / 百万 token”显示按本周期实际构成计算的参考权重。加权占比的分母为本机本周期所有纳入计权的记录。当前内置 2026 年 11 月 18 日核对的费率，覆盖相关模型的标准档及有公布积分倍率的 Fast 档。缺少费率或档位时保留原始用量。

模型表先按截至快照的本机计费权重分摊账户已用额度，并用 `≈` 标记。组合有拟合结果后，先采用该结果，再按权重分摊剩余额度。拟合结果占满快照且仍有待分摊组合时，本次占比统一按权重计算。

### 周配额系数

- **暂估（≈）**。首段达到 1 个百分点的单组合区间可用于暂估该组合。多个组合可从充分且独立的样本拟合。发布暂估需要该组合出现在本周期有效区间中。近期样本权重更高。
- **已验证**。模型组合通过独立验证后，采用通过验证的系数。含多种依据的会话按可信度最低的一项标记。账户或快照无法确认时，显示“待数据”。

本机估算合计比账户快照高出 1 个百分点时，暂停应用相应拟合结果。只有单张账户快照或缺乏可分离样本时，周配额系数等待更多数据。模型页保留近 28 天内的历史与本周期拟合区间数。

### 验证系数

使用最近 28 天同一账户和套餐的记录。样本按时间排列，每个区间的起点不计、终点计入。正式验证要求区间至少变化 3 个百分点。配额回退后等待重新达到已有记录的最高值，再开始新区间。同一时刻快照冲突、套餐变化、重置、长时间间隔及饱和会中断区间。缺失日志和无法归因的用量会排除相关区间。

较早约 75% 的区间用于拟合，较新约 25% 用于留出验证。模型形式在训练区间内选择。若独立样本足够，尝试分别拟合未缓存输入、缓存输入和输出。留出集上的误差对应实际采用的系数。

全部留出区间和本周期子集的平均绝对误差均须不超过 1.25 个百分点，并通过累计偏差检查。多组合或分通道模型还须比统一 token 换算降低至少 10% 且 0.15 个百分点的误差。单组合总 token 模型按绝对误差验证。每个采用的组合须在本周期至少 3 个留出区间内有足够用量，并能与其他组合分开验证。

周重置后，暂估继续随可用数据更新。前期验证系数可作参考。配额取整、跨设备或云端消耗，以及本机日志缺失都会影响估算。账户配额与本机估算之间的差值无法单独用来衡量其他设备用量。
