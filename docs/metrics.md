# 用量、速率与校准

## token

优先使用按响应 ID 去重的 `token_usage_record`。旧日志使用累计值差分；累计计数回退时只采用明确记录的单次请求用量。分叉继承的父会话记录按所有权与创建时间排除。

缓存输入已包含在输入中，推理输出已包含在输出中，均不重复相加。每行只计会话自身，详情可另看自身与子树合计。

日志被清理时保留已有缓存。只有元数据累计快照的会话无法还原每日和本周用量，会显示覆盖说明。

## 速度

- 近 1 分钟输出速率：窗口内输出 token / 60。
- 近 5 分钟输出速率：窗口内输出 token / 300。
- 非缓存消耗：未缓存输入 + 输出，折算为 token/min。
- 响应频率：窗口内完成并记账的模型响应数。
- 本轮平均输出：本轮输出 / 从开始到当前或结束的墙钟时间，包含工具、排队和等待。
- 已记录命令耗时：合并命令起止区间，重叠部分只计一次。

固定窗口不会随刷新间隔改变分母。首个响应入账等待不等于首 token 延迟；模型纯生成速度不能由这些日志准确还原。

## 周配额

账户周配额是日志中的快照。有效周期取重置时间之前的 7 天；快照缺失或过期时采用北京时间自然周，并停止配额分摊。所有显示时间均为北京时间。

“token 分摊参考”按本机周期 token 比例分配账户快照，仅供对照。它与自动学习的“校准占比”分别显示。

## 自动校准

按模型、思考深度和服务档位分组。历史维度缺失时保留“未记录”，不会用当前设置补填。新模型形成新组并自动积累样本。

使用最近 28 天同一账户与套餐的记录。账户标识只保存哈希。配额变化至少 3 个百分点形成一个非重叠区间；合并重置时间相差 120 秒以内的快照。超过 2 小时的采样空档、计数回退、重置、100% 饱和、日志缺失和上下文不明的区间不参加拟合。

较早约 75% 的区间用于学习，较新约 25% 用于验证，至少保留 5 个验证区间。样本不足或长期固定比例混用的组合显示“待校准”。少见组合所在的混用区间会排除，避免将其消耗转给其他组合。

通过标准：验证平均绝对误差不超过 1.25 个百分点，相比统一 token 换算至少降低 10% 且降低 0.15 个百分点，并检查累计偏差。这些是程序的启用门槛。

先学习每百万总 token 对应的配额百分点。样本足够且输入结构可分离时，再拟合未缓存输入、缓存输入和输出系数。非负拟合落在零边界的组合视为尚不可可靠分离。

每个合格组合可独立启用。周重置保留历史学习结果，但当前周期通过验证前只作历史参考。近期验证失败会停用估算。配额取整、其他设备、云端用量和不可见日志都会影响准确度。

校准截至最近配额快照，不强制凑齐账户总消耗。包含未校准组合的会话显示“待校准”；本机合计与账户快照之差不直接解释为其他设备用量。
